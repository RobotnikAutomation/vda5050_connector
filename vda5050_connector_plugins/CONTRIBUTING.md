# Contributing to this Project

Thank you for considering contributing! We welcome contributions in the form of new features, bug fixes, or improvements.

Please follow these guidelines to ensure smooth collaboration.

## Branching Guidelines

- All contributions should be done through **Pull Requests (PRs)**.
- Create a new branch from `devel` for your contribution.
- Branch names must follow this pattern:
  - `feat/<short-description>` for new features
  - `fix/<short-description>` for bug fixes
- Example:
  ```bash
  git checkout devel
  git pull origin devel
  git checkout -b feat/add-login-feature
